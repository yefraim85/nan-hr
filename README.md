# Nan HR

A static one-page bilingual (English/Thai) website for Nan HR, a recruitment agency.

## Run locally

Plain static site — no build step. Serve it with the bundled Node dev server (no dependencies):

```bash
node tools/dev-server.js
```

Then open http://localhost:5173. You can also just open `index.html` directly in a browser.

## Deploy

Hosted on GitHub Pages from the `main` branch root — pushing to `main` redeploys automatically.
